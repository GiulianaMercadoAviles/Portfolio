# Portfolio

Portfolio personal de Giuliana Mercado Aviles, desarrollado con React, TypeScript y Vite.

## Desarrollo local

Instala las dependencias y ejecuta el servidor de desarrollo:

```sh
npm install
npm run dev
```

## Produccion

Genera la version de produccion con:

```sh
npm run build
```

Para revisar el codigo, ejecuta `npm run lint`.
